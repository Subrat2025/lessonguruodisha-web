📖 Section 5: Very Short Answer 1 Question
Easy 1 Mark
Define an "equivalent fraction".
Fractions that represent the same value, like 1/2 and 2/4.
📚 Section 6: Short Answer 1 Question
Medium 2 Marks
Explain how to multiply two fractions with an example.
Multiply numerators together and denominators together.
Example: 1/2 × 2/3 = (1×2)/(2×3) = 2/6 = 1/3.
📝 Section 7: Long Answer 1 Question
Hard 5 Marks
Describe with examples how to add fractions with different denominators.
Find a common denominator (LCM), convert each fraction, then add numerators.
Example: 1/2 + 1/3. LCM = 6, so 3/6 + 2/6 = 5/6.
🧠 Section 8: Competency-Based Questions 1 Question
Hard 3 Marks
Ravi ate 3/8 of a pizza. Sita ate 1/4. Who ate more, and by how much?
Ravi ate more, by 1/8.
3/8 = 3/8, 1/4 = 2/8. Difference = 1/8.
