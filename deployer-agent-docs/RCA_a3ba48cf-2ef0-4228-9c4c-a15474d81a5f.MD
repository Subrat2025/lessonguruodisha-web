## Root cause (from Cloud Build logs, build e1bd9fff-b665-4067-84ce-bed74961477e)
`yarn build` (Next.js production build) failed during static generation/export. Two code problems surfaced:

### 1) FATAL — prerender/export error on `/store/checkout`
```
#22 67.13  ⨯ useSearchParams() should be wrapped in a suspense boundary at page "/store/checkout".
           Read more: https://nextjs.org/docs/messages/missing-suspense-with-csr-bailout
#22 67.13 Error occurred prerendering page "/store/checkout".
#22 96.49 > Export encountered errors on following paths:
#22 96.49 	/store/checkout/page: /store/checkout
#22 96.78 error Command failed with exit code 1.
ERROR: executor failed running [/bin/sh -c yarn build]: exit code: 1
```
In the Next.js App Router, a client component that calls `useSearchParams()` must be wrapped in a `<Suspense>` boundary, otherwise the page cannot be statically prerendered and the build aborts.

### 2) Module-not-found in `./lib/gemini.js`
```
./lib/gemini.js
Module not found: Package path ./package.json is not exported from package
/app/node_modules/@google/genai (see exports field in /app/node_modules/@google/genai/package.json)
```
Code is importing `@google/genai/package.json` (or a subpath that the package's `exports` field does not expose). Newer `@google/genai` versions restrict subpath imports via the `exports` map, so this import resolves to nothing.

## Required fixes (Code — owned by E1)

### Fix A — wrap `/store/checkout` search-params usage in `<Suspense>`
In `app/store/checkout/page.js` (or `page.tsx`), move the component that calls `useSearchParams()` into a child client component and wrap it:
```jsx
import { Suspense } from "react";

function CheckoutInner() {
  const searchParams = useSearchParams();
  // ...existing checkout logic...
}

export default function CheckoutPage() {
  return (
    <Suspense fallback={<div>Loading…</div>}>
      <CheckoutInner />
    </Suspense>
  );
}
```
(Alternatively add `export const dynamic = "force-dynamic";` to the checkout route to opt it out of static prerendering — the `<Suspense>` wrap is the recommended fix.)

### Fix B — remove the invalid `@google/genai/package.json` import in `lib/gemini.js`
Locate the line importing `package.json` from `@google/genai` and remove it (it is usually a version/debug read). Import only the public API, e.g.:
```js
import { GoogleGenAI } from "@google/genai";
```
Do not import `@google/genai/package.json` — that subpath is not exported.
